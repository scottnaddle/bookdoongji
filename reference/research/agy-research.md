> 조사일: 2026-10-18
> 방법: agy 에이전트 웹 리서치 + 직접 기술 분석 (HTTP 헤더, HTML 소스, JS 번들)
> 주의: 실제 상품 데이터/이미지/문구는 수집하지 않음. 구조·기능 위주.

## 1. 서비스 개요

- **서비스명**: 스콘북카페 (sconn.io) — "교재 구매부터 필기까지 한곳에서"
- **운영사**: Flexcil Inc. (주식회사 플렉슬) — 글로벌 디지털 필기 앱 Flexcil 개발사
- **포지셔닝**: 한국 수험서·대학교재 전문 디지털 전자책(eBook) 플랫폼

### 주요 취급 상품
- 공무원 수험서 (9급/7급/경찰/소방/군무원 등)
- 국가고시 교재 (간호사, 의사, 약사, 보건의료 등)
- 자격증·어학 수험서 (토익, 한능검, 공인중개사 등)
- 취업/NCS/인적성 교재
- 초·중·고 참고서 및 EBS 수능 연계교재
- 대학교재 (전공 계열별)
- 디지털 문구/서식 (노트/속지, 스티커, 플래너 템플릿 등)

### 판매·제공 모델
| 모델 | 설명 |
|---|---|
| **소장** | 영구 소장형 전자책 구매 |
| **대여** | 시험 주기/학기에 맞춘 기간제 열람 (예: 시험 당해 1월 31일까지) |
| **구독패스 (PASS)** | 1타 강사/시리즈 교재 전체를 월 정액으로 무제한 열람 (월 정기결제) |
| **스마트 eBook** | 전자 OMR 마킹, 실시간 자동 채점, 타이머/시험 모드, 자동 오답노트 연동 인터랙티브 교재 |
| **무료 도서** | 기출문제, 봉투 모의고사, 출판사 샘플북/체험판 무료 제공 |

### 결제·충전금 모델
- 자체 선불 충전금 **'스콘(SCONN) 포인트'** 운영 (1만/3만/5만원 충전 시 보너스 적립금)
- 토스페이먼츠 연동 (신용카드, 간편결제), 할인 쿠폰 등록/적용

## 2. 기술 스택 추정 (직접 분석)

### 프론트엔드
- **Next.js (App Router)** — `x-powered-by: Next.js` 헤더, `/_next/static/chunks/main-app-*.js` 확인
- CSS: Next.js 빌트인 CSS 청크 2개
- 정적 에셋: `https://cdn.sconn.io` (CloudFront)

### 인프라
- **AWS CloudFront** CDN (`X-Cache`, `Via: ...cloudfront.net`, PoP SEA73)
- `Strict-Transport-Security`, `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`
- `Cache-Control: no-store` — SSR 페이지

### 백엔드 힌트
- API: `https://front-api.dev2.sconn.io` (CSP connect-src에 노출)
- 에러 트래킹: `bugsink.withflexcil.com` (Flexcil 자체)

### 서드파티 연동
- **토스페이먼츠** (결제)
- Google Tag Manager / Google Ads / Facebook Pixel
- YouTube 임베드
- **Airbridge** — 모바일 딥링킹/어트리뷰션

### 서브도메인 구조
| 서브도메인 | 용도 | 비고 |
|---|---|---|
| `sconn.io` | 메인 웹 (Next.js) | 실측 확인 |
| `cdn.sconn.io` | 정적 에셋 CDN | 실측 확인 |
| `product.sconn.io` | 스콘 앱/리더 사용 가이드 허브 | Notion + Oopy 기반 (실측: Airbridge 리다이렉트) |
| `ebook.sconn.io` | eBook 리더 (앱 딥링크) | 미인증 시 sconn.io로 리다이렉트 (실측) |
| `business.sconn.io` | B2B | 메인 HTML에서 링크 확인 |
| `scm.sconn.io` | 출판사/CP 관리 콘솔 | agy 확인 |
| `front-api.dev2.sconn.io` | 프론트 API | CSP에서 확인 |

## 4. eBook 리더 (스콘 앱)

> `product.sconn.io`는 독립 웹 리더가 아니라 **Notion + Oopy 기반의 공식 사용 가이드 허브**. 실제 열람·필기는 **스콘 앱**에서 실행.

### 핵심 기능 (Flexcil 엔진)
- **필기/펜 커스텀**: 만년필/볼펜/형광펜, 굵기/색상/투명도 프리셋, 다중 펜 슬롯
- **제스처 모드**: 밑줄(`_`)/꺾쇠(`ㄱ`,`ㄴ`)/박스(`ㅁ`) 그리면 텍스트 인식 → 하이라이트/복사/검색
- **드래그 앤 드롭 스크랩**: 본문 → 요약/오답 노트로 바로 복사
- **레퍼런스 링크**: 스크랩 발췌문에 원본 교재 페이지 하이퍼링크 자동 생성
- **팝업 뷰어/분할 보기**: 3핑거 스와이프로 해설지 오버레이
- **마스킹 펜**: 암기 단어 가리기/탭으로 열기 (자가 진단)
- **포인터**: 레이저 포인터
- **시험 모드/스마트 OMR**: OMR 패널 마킹 자동 반영, 타이머, 원터치 자동 채점, 오답노트 자동 생성
- **뷰어 설정**: 좌우/상하 스크롤, 1/2/4쪽 보기, 테마 (라이트/다크/그레이/세피아)

### PC/웹 리더 정책
- **일반 사용자: PC 웹 리더 미지원** (DRM 보안상) — 태블릿/스마트폰 앱 전용
- **교강사 전용 예외** (스콘 for Teacher): 승인 회원은 내 서재에서 '웹에서 보기' 가능 (필기 미동기화)

## 6. 핵심 UX 패턴

### 상품 카드
- 썸네일: 8px 라운드 코너, 블러 플레이스홀더 + 레이지 로딩
- 스마트 OMR 지원 도서는 썸네일 상단 전용 아이콘
- 판매 유형 뱃지 (Pill): `구독` / `대여` / `무료`
- 도서명: 최대 3줄 말줄임 (`line-clamp-3`)
- 저자명 클릭 → 해당 저자 도서 필터링 / 출판사명 병기
- 소장/대여/구독별 라벨·폰트 색상 차별화

### 가격 표시
| 구분 | 뱃지 컬러 | 표기 패턴 | 조건 |
|---|---|---|---|
| 소장 | 일반 텍스트 | 할인율 + 정가(취소선) + 실결제금액 | 영구 열람 |
| 대여 | 퍼플 (`text-sconn-purple-700`) | 할인율 + 정가 + 대여금액 | 만료일 명시 (예: 2027년 1월 31일까지) |
| 구독패스 | 그린 (`text-sconn-green-800`) | `구독 월 19,900원` | 월 정기결제/자동갱신 |
| 무료/체험 | 옐로우 (`bg-sconn-yellow-200`) | `무료` / `0원` | 기출/체험판 |

### 카테고리 네비게이션
- 2단계 계층형: GNB 햄버거 → 대분류 → 브레드크럼/가로 스크롤 칩으로 하위 분류 확장
- URL: `/product-category/{부모ID}-{자식ID}`
- 수험 특화 분류: `9급 → 직렬(일반행정/세무/교정) → 과목(국어/영어/한국사) → 교재 성격(기본서/기출/어휘/파이널)`
- 보건의료 국시 (간호사/의사/한의사 등) 독립 카테고리
- 대학교재는 단과대 계열별 트리
- 디지털 문구 (노트/스티커/플래너) 독립 카테고리

### 수험서 특화 기능
- D-day 시험 일정 (`/guides/exam-schedule`): 접수일/시험일/발표일/시간표
- 무료 기출·체험판 전용관 (`/free-books`): 뷰어 체험 유도
- 교강사 채널: 수업용 도서 신청 + PC 웹뷰
